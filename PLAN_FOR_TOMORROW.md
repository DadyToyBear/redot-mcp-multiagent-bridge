# План на завтра (записано по просьбе пользователя)

## 1. Задания с отметкой выполнения
- Вкладка 💬 Чат → блок «✅ Задания» уже показывает список `assign-*.json`.
- Выполненное задание автоматически **зачёркивается** и помечается «✅ выполнено»,
  если агент загрузил `result-<id>.json` с `result.status = "done"`.
- Агент обязан после выполнения: написать «Готово: ...» в комнату, загрузить result с отчётом.
- Оператор может поставить галочку вручную — это тоже пишет result с status=done.

## 2. Отчёты
- Каждое задание: короткий отчёт (что сделано / что проверено / что осталось).
- Отчёт кладётся в `result-<id>.json` и дублируется в общую комнату.

## 3. Временные скриншоты (режим исчезающих сообщений)
- `screenshot-*.png` и `frame-*.png` **удаляются автоматически через 15 минут**
  (демон `/root/shotclean.py` на OrangePi, работает с файловой системой, не через WebFTP DELETE).
- Правило для агентов: закончил этап / починил код — удали свои скриншоты сразу.
- Если скриншот нужен как постоянный артефакт — переименуй в `artifact-*.png` (не удаляется).

## 4. Интерфейс
- Одна вкладка Live, сетка 2×2: редактор | живой кадр (2с, в памяти) | логи | управление.
- Отдельные вкладки Редактор/Запись/Трансляция убраны по просьбе chat.z.ai.

Правила для агентов: RULES_FOR_AGENTS.md на шаре.
