# Настройка своего MCP Dashboard (с нуля)

Этот шаблон не содержит ни одного реального адреса, токена или ключа.
Вы используете **только свои** серверы, домены, IP и ключи.

## 1. Что понадобится

- Свой WebFTP (или другой файловый брокер) с шарой `read/write`.
- Свой HTTP- или HTTPS-источник для редактора. Для Godot Web нужен **HTTPS**
  и заголовки `COOP: same-origin`, `COEP: require-corp`, `CORP: cross-origin`
  (иначе SharedArrayBuffer недоступен).
- Свой bridge, который ходит на `ws://127.0.0.1:6505…6514` и опрашивает шару.
- Свой LLM API-ключ. Используйте переменные окружения, не коммитьте ключ.

## 2. Заполните конфиг

Скопируйте `config.example.json` → `config.json` и замените:

| Плейсхолдер | Что вставить |
|---|---|
| `<YOUR_WEBFTP_SHARE_URL>` | URL вашей шары, например `https://example.com/s/<your_token>` |
| `<YOUR_HTTPS_ORIGIN>` | Ваш HTTPS-источник |
| `<YOUR_EDITOR_URL>` | URL вашего `godot.editor.html` |
| `<YOUR_MODEL_1/2>` | Модели, которые вы сами выбрали и оплачиваете |
| `{env:YOUR_LLM_API_KEY}` | Переменная окружения с вашим ключом |
| `{env:YOUR_PROXY_URL}` | Ваш прокси, если он нужен |

## 3. Откройте тестовый дашборд

`dashboard.template.html` — пустой рабочий каркас:

1. Введите URL своей шары и редактора → «Применить».
2. «🧪 Тестовый вызов MCP» пишет `task-<id>.json` и ждёт `result-<id>.json`.
3. «📋 Задания» показывает `assign-*.json`; выполненное зачёркивается,
   если есть `result-<id>.json` со статусом `done`. Галочку можно поставить вручную.

## 4. Правила безопасности

- Не публикуйте чужой токен шары и чужой API-ключ.
- Не используйте чужой сервер без разрешения.
- Храните ключи в переменных окружения: `WEBFTP_SHARE`, `OPENROUTER_API_KEY`, `OR_PROXY`.
- Скриншоты делайте временными: удаляйте `screenshot-*.png` после этапа
  или настройте TTL (см. `RULES_FOR_AGENTS.md`).

## 5. Протокол

Форматы файлов — в `CHAT_PROTOCOL.md`. Примеры моста — `bridge.py`, `mcp_call.py`.
